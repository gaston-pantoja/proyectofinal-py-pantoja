# Plataforma Vanguardia - Innovación y Sostenibilidad Industrial

Aplicación web estilo Blog desarrollada en Python utilizando el framework Django. Este proyecto corresponde a la entrega final del **Playground Final Project**.

## Funcionalidades Implementadas

- **Gestión de Páginas (CRUD):** Creación, visualización, edición y borrado de artículos utilizando Vistas Basadas en Clases (CBV) y optimización con filtros avanzados.
- **Seguridad (Mixins y Decoradores):** Restricción de acceso para usuarios no autenticados en los flujos de edición y creación mediante `LoginRequiredMixin`.
- **Sistema de Cuentas (Accounts):** Registro, inicio de sesión, cierre de sesión y gestión de perfiles de usuario con soporte para avatares y biografías.
- **Mensajería Interna:** Canal de comunicación asíncrono integrado para que los usuarios registrados se envíen mensajes entre sí.
- **Interfaz Premium:** Diseño unificado en modo oscuro nativo, responsivo y adaptado para evitar sobrecarga visual.
